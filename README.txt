Dataset Name:
Student Performance Dataset

Source:
Kaggle

Number of Rows and Columns:
The dataset contains 1000 rows and 8 columns.

Features Description:

gender: student gender
race/ethnicity: student group
parental level of education: education level of parents
lunch: type of lunch
test preparation course: whether student completed preparation course
math score: score in math
reading score: score in reading
writing score: score in writing

Purpose of the Dataset:
The purpose of this dataset is to analyze student performance and identify factors that affect academic results using exploratory data analysis (EDA).
